# Huellas-del-cibao (Clínica Veterinaria)
Hackathon 
Proyecto de pagina web para una clínica veterinaria ubicada en Santiago (Huellas del cibao).

La pagina tiene la misión de facilitar el acceso a la información de las mascotas de sus clientes (Principalmente calendario de vacunación).

objetivos

Crear un sitio web organizado y facil de utilizar donde los propietarios puedan:

- ver el calendario de vacunacion de los animales por especio
- ver la solicitudes de cita: dueño, teléfono, correo, nombre y especie de la mascota, edad, fecha deseada, motivo de la consulta y si es primera visita
- Un video corto sobre cómo bañar a un perro en casa
- las instalaciones y el equipo de la clínica


Paginas del sitio

El sitio estará compuesto por las siguientes paginas:

- Inicio
- Servicios
- Calendario de vacunación
- Consejos de cuidado
- Pedir cita
- Contacto


El calendario de vacunación estará organizado por especie.

La tabla mostrará las vacunas correspondientes dependiendo de la edad del animal.

Se utilizarán filas para representar las vacunas y columnas para representar las edades.

Cuando una misma vacuna corresponda a varias edades se podrán combinar las celdas para que la tabla sea más clara.

(Ojo, muy importante) El calendario de vacunación es la página más visitada del sitio: debe entenderse de un vistazo, sin leer párrafos.


El formulario para solicitar una cita tendrá los siguientes datos:

- Nombre del dueño
- Teléfono
- Correo
- Nombre de la mascota
- Especie de la mascota
- Edad
- Fecha deseada
- Motivo de la consulta
- Indicar si es la primera visita

Contenidos multimedias

La pagina tendrá un video corto sobre cómo bañar correctamente a un perro en casa.

Este contenido se encontrara en la sección de consejos de cuidado.

Imagenes

La pagina mostrará imagenes de:

- Las instalaciones de la clínica
- Los consultorios
- El equipo utilizado
- Areas de atención para las mascotas

Tecnologías utilizadas

Para la creación de este proyecto se utilizarán principalmente:

- HTML
- CSS
